This is your first post. Write in plain **Markdown** — headings, links, lists, quotes, and code all work.

## How to write a new post

1. Create a markdown file in `blog/posts/`, e.g. `my-next-post.md`
2. Add one entry to the list in `blog/posts.js`:

```js
{
  slug: "my-next-post",
  title: "My Next Post",
  date: "2026-09-01",
},
```

That's it. The post appears on the blog page automatically.
